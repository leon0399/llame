# `read` for web URLs compared

llame's `read` on `http(s)://` next to other harnesses' web fetch tools. Add a
harness as a column, a capability as a row. llame's behavior is owned by [web
locators](../../product/reference/locators/web.md) and [web
adapters](../../product/reference/web-adapters.md).
