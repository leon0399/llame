# `read` for web URLs compared

How llame's `read` tool handles `http(s)://` locators next to the web fetch
tools of other agent harnesses. Columns are harnesses, so a new harness is one
more column; rows are capabilities, so a new capability is one more row. The
behavior llame ships is owned by [web locators](../../product/reference/locators/web.md)
and [web adapters](../../product/reference/web-adapters.md); this page is a
contributor's comparison and loses to them on any disagreement.

handler's source at the observed revision; its endpoints are not restated here.
