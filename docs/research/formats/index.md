# Knowledge and interchange formats

Noncanonical references for specifications used to represent or exchange
knowledge. A format can include a reference producer or viewer without becoming
an agentic harness.

- [Open Knowledge Format](./open-knowledge-format.md) — Markdown/YAML concepts,
  progressive disclosure and optional provenance, verification and freshness
  metadata.

See [agentic harnesses](../harnesses/index.md) for execution runtimes and
[tools and extensions](../tools/index.md) for supporting software. The upstream
specification defines its format; llame's own specs define whether and how the
application uses it.
