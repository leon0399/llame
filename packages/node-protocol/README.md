# Common owner-access protocol

Versioned operation contracts shared by two real runtime adapters. Includes strict
request/argument validation, capability discovery, principal/source observations,
HTTP subject assertions, and OpenAPI extensions. It contains neither application
storage nor provider/tool execution.

The common core/realm version is 1; it is independent of personal private IPC's
version 2. See [shared access](../../docs/node/shared-access.md) and the
[capability spec](../../openspec/specs/node-access/spec.md).
